# Frame mode — bundled paintings

Twenty public-domain works, shown by `FrameActivity` (`docs/frame.md`). The files here are 3840×2160
(16:9) centre crops of the Wikimedia Commons scans, re-encoded at high quality (q84–q92); the app
decodes them at about the panel's size, so a 1080p box never holds a 4K bitmap in memory. The
originals (3.4–13K wide) are linked below and can be re-cropped by a future build without a new
download.

The six files whose source carried an ICC profile were re-encoded without it: the LEAP-S1's JPEG
decoder tiles some 4K files that embed one. The paintings are sRGB, so nothing visible changes.

Every work is in the public domain (the artists died more than 70 years ago, and these are faithful
reproductions of two-dimensional works). The links below are the source files, with the full
resolution available.
